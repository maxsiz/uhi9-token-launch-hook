# TokenLaunchHook Studio (web)

Web3 frontend **and live demo** for the `TokenLaunchHook` Uniswap v4 hook. Full spec:
[`../tasks/DESIGN.md`](../tasks/DESIGN.md).

- **Launch Wizard** — build + sign one `CampaignWrapper.launchCampaign` transaction.
- **Governance Dashboard** — relax taxes / lock / whitelist as the governance-NFT owner.
- **Hook Transparency Layer** — every feature shows which hook callback + mechanism it exercises
  (`lib/hook/hookMap.ts` + `components/hook/*`). This is what makes the app a demo for the hook.

## Stack

Next.js (App Router) · wagmi v2 · viem v2 · RainbowKit (MetaMask + Rabby via EIP-6963) ·
`@uniswap/v4-sdk` · TypeScript · Tailwind.

## Develop

```bash
cp .env.local.example .env.local      # set NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID (+ RPCs)
npm install
npm run gen:contracts                 # generate per-chain addresses from broadcast JSON (no-op until deployed)
npm run dev                           # http://localhost:3000
npm run typecheck                     # tsc --noEmit
```

## Contract config

- **ABIs** — committed under `lib/config/abi/` (extracted from Foundry `out/`), so the build needs no
  Foundry toolchain. Re-extract when the contracts change.
- **Addresses** — `lib/config/contracts.generated.ts` is generated by `scripts/gen-contracts.ts`
  from `../broadcast/DeployStack.s.sol/{chainId}/run-latest.json`. Chains without a deployment stay
  at the zero address and are shown as "not yet available".
- **Canonical Uniswap + Permit2** — hardcoded in `lib/config/uniswap.ts` (mirrors
  `script/MineSalt.s.sol` `HookDeployLib.canonical()`).

## Deploy (Vercel)

Root Directory = `web/`. Build `next build` (with `prebuild` codegen). Set
`NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` and optional per-chain RPC env vars. No private keys — all
signing is client-side.
